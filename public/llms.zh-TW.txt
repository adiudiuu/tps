# TPS Calculator（繁體中文）

> 按 GPU、模型、量化與推理框架，估計 LLM 的推理速度（token/s）、顯存佔用與延遲。

站點：https://tps.bunai.com/
源碼：https://github.com/adiudiuu/tps
其他語言：[簡體中文](/llms.zh.txt) / [English](/llms.txt) / [Русский](/llms.ru.txt) / [Español](/llms.es.txt) / [한국어](/llms.ko.txt) / [日本語](/llms.ja.txt)
界面：簡體中文預設（不加 lang）；`?lang=zh-TW`（繁體中文）/ `?lang=en` / `?lang=ru` / `?lang=es` / `?lang=ko` / `?lang=ja`

## 計算內容

- Decode / Prefill TPS
- 顯存：權重、KV Cache、開銷；標出可能 OOM
- 延遲：TTFT、TPOT、端到端
- Roofline：頻寬 vs 算力
- 多卡 Tensor Parallel

基於 Roofline 與公開規格 × 框架效率。理論上界，非實測榜。
